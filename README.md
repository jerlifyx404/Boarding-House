# 🏠 Boarding House Management and Reservation System

The **Boarding House Management and Reservation System** is a platform that simplifies boarding house management and reservation. It consists of a **mobile application** for Tenants and Boarding House Owners and a **web-based application** for Administrators.

## 📱 Mobile Application

### Tenant Features
- View available boarding houses
- View boarding house details and locations
- Submit reservation requests
- Receive request notifications

### Owner Features
- Add, edit, and delete boarding house information
- Manage boarding house locations
- View tenant reservation requests
- Approve or decline requests

## 💻 Web Application

### Administrator Features
- Manage user accounts
- Monitor tenant requests
- Centralized system management

## ⚠️ Note

> This project is developed for **educational and project purposes only**. It is not intended for commercial use or real-world deployment.
